### Type of html tag based on appearance

1.  inline
    -- flexible element
    -- width and height can not be manipulated
2.  block
    -- 100% width
    -- height and width are customizable
3.  inline-block
    -- flexible element
    -- height and width are customizable
4.  flex (parent tag/element)
